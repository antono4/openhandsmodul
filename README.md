# 📚 OpenHands Documentation Hub

Portal dokumentasi komprehensif untuk platform pengembangan berbasis AI OpenHands.

![Version](https://img.shields.io/badge/version-1.6.1-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## 🎯 Tentang Proyek

OpenHands Documentation Hub adalah antarmuka web yang menyediakan akses mudah ke semua dokumentasi resmi OpenHands. Dibangun dengan antarmuka modern dan responsif, situs ini memungkinkan pengguna untuk:

- **Pencarian Cepat** - Temukan dokumentasi yang dibutuhkan dengan mudah
- **Navigasi Terstruktur** - Dokumentasi dikelompokkan berdasarkan kategori
- **Akses ke Sumber Resmi** - Langsung menuju ke dokumentasi lengkap di situs resmi

## ✨ Fitur

- 🔍 **Pencarian Real-time** - Filter dokumentasi secara instan
- 📱 **Responsif** - Tampilan optimal di semua perangkat
- 🎨 **UI Modern** - Desain dark theme yang nyaman di mata
- ⚡ **Performa Tinggi** - Loading cepat dan navigasi smooth
- 🌐 **Multi Bahasa** - Dokumentasi dalam Bahasa Indonesia

Bergabung dengan komunitas OpenHands, berkontribusi, dan mendapatkan bantuan.

## 🚀 Cara Menggunakan

1. **Buka `index.html`** di browser mana pun
2. **Gunakan kotak pencarian** untuk menemukan dokumentasi
3. **Klik kartu** untuk menuju ke dokumentasi resmi
4. **Gunakan shortcut keyboard** `/` untuk fokus ke pencarian

## 🛠️ Pengembangan

Proyek ini adalah file HTML statis yang dapat dijalankan langsung tanpa server.

```bash
# Clone repository
git clone <repo-url>

# Buka di browser
open index.html
```
